Present Simple & Past Simple Game

Правила использования Present Simple:

Present Simple используется для выражения регулярных действий, фактов и привычек.

  • Для I/You/We/They используется основная форма глагола.
  • Для He/She/It добавляется окончание -s или -es (например, plays, goes).
  • Для вопросов используется вспомогательный глагол do/does: Do you play? / Does she play?.
  • Для отрицания используется don’t/doesn’t: I don’t play / She doesn’t play.

Правила использования Past Simple:

Past Simple используется для выражения действий, которые произошли в прошлом и завершены.

  • Для большинства глаголов в Past Simple используется форма с окончанием -ed (например, worked, played, watched).
  • Некоторые глаголы имеют неправильную форму (например, went, saw, did).
  • Для отрицания в Past Simple используется вспомогательный глагол did в форме отрицания didn't.
  • Для вопросов используется вспомогательный глагол did в начале предложения: Did you go?
